# Implementation Records

These documents are resumable, medium-high-level handoffs for implementation work. Architecture documents explain the intended system; implementation records explain what the working tree currently contains, why it was built that way, how it was verified, and what remains.

## Records

- [Phase 1: Executable Baseline](./phase-01-executable-baseline.md)

## Update rule

Update the active record during implementation and before every commit or session handoff. Include observed command results rather than expected results. A blocked check remains visibly blocked until it is rerun successfully.
