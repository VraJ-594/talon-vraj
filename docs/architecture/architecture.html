Hiring, connected end to end.

A navigable engineering brief for the Talon ATS: tenant-safe data, reliable hiring workflows, replaceable integrations, and an AWS path sized for a fast first release.

Architecture spine

Five decisions hold the system together.

These are deliberate constraints. They prevent the first release from turning into a distributed platform before the product workflows have earned that complexity.

React/ViteStrict TypeScript SPA for the authenticated desktop product.
Spring BootOne modular Java backend with API and worker profiles.
Supabase PostgreSQLFree for demo; paid backups and non-pausing compute required for production.
SQS outboxSlow provider work remains durable and outside request threads.
ECS FargateStandard containers without operating EC2 hosts or Kubernetes.
